# System Instructions

This repository contains the core guidelines and workflow instructions for AI agents working on the Kalgo project.

## Contents

- **[INSTRUCTIONS.md](INSTRUCTIONS.md)**: AI workflow definitions, including phase control (Plan, Review, Implement), Caveman Mode, and output efficiency rules.
- **[.agents/](.agents/)**: Reusable AI skill modules and system prompt templates.

## Usage

1. **Setup**: Run the installation script to deploy rules to your preferred AI tool:
   ```bash
   bash .agents/install.sh  # Unix
   .\.agents\install.bat    # Windows
   ```
2. **Workflow**: AI agents should read these files at the start of a session and before beginning new implementation phases to ensure compliance with project standards and workflows.
