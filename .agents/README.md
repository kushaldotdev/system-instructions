# Agent Skills

## Structure
```
.agents/
├── install.sh                       ← run this once
├── SYSTEM_PROMPT.md                 ← source of truth, edit this
└── skills/
    ├── plan/SKILL.md
    ├── review/SKILL.md
    └── implement/SKILL.md
```
Generated by install.sh (do not edit manually):
```
.agents/.system_prompt_patched.md    ← absolute paths injected
.agents/.system_prompt_antigravity.md ← same + Antigravity frontmatter
```

## Install
Place `.agents/` in your project root, then:
```bash
bash .agents/install.sh
```
Re-run any time you edit `SYSTEM_PROMPT.md`.

## What the script does per tool

| Tool | File linked | Notes |
|---|---|---|
| Claude Code | `CLAUDE.md` | Project root |
| Cline | `.cline/rules/agent-skills.md` | Symlinked into rules dir |
| Kilocode | `.kilo/rules/agent-skills.md` + `kilo.jsonc` | Script edits/creates `kilo.jsonc` |
| Antigravity | `.agent/rules/agent-skills.md` | Wrapped with `trigger: always_on` frontmatter |

## claude.ai (computer use)
Skills need manual install — copy folders to root:
```
skills/plan/      → .agents/skills/plan/
skills/review/    → .agents/skills/review/
skills/implement/ → .agents/skills/implement/
```
Use `SYSTEM_PROMPT.md` as-is.

## Editing the system prompt
Edit `.agents/SYSTEM_PROMPT.md` only.
Run `.agents/install.sh` after — it regenerates the patched files and refreshes all symlinks.
